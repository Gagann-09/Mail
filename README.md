# Mail

An original email web application organized around human intent, attention, and unfinished work.

## Status

**Phase 1 — Product Definition** (complete, pending approval)

No implementation has been authorized.

## Project

Mail is a first-principles email workspace. It is not a clone of Gmail, Outlook, Yahoo Mail, Proton Mail, Apple Mail, Thunderbird, or Fastmail.
